# Hospital-Weekend-Effect-Analysis

An end-to-end Healthcare Analytics project combining Informatica  and Power BI to analyze the Weekend Effect in hospital admissions using the MIMIC-III Clinical Database Demo.

---

## Project Overview

The project includes:
- ETL pipeline development using Informatica IDMC
- Clinical data integration and transformation
- Interactive Power BI dashboard for healthcare insights

---

## Tech Stack

### ETL & Data Engineering
- Informatica Intelligent Data Management Cloud (IDMC)
- ETL
- Data Integration
- Data Modeling

### Dashboard & Visualization
- Power BI
- Power Query
- DAX

---

## ETL Workflow

- Integrated PATIENTS, ADMISSIONS, and ICUSTAYS datasets
- Performed data cleansing and transformation
- Engineered analytical metrics including:
  - Weekend Flag
  - Hospital Length of Stay (LOS)
  - ICU Length of Stay
  - Mortality Flag
  - Age at Admission
- Prepared the transformed dataset for Power BI reporting

---

## Dashboard Features

### KPI Metrics
- Total Admissions
- Weekend Admissions
- Weekday Admissions
- Overall Mortality Rate
- Average Hospital LOS

### Weekend Effect Analysis
- Mortality Rate Comparison
- Hospital LOS Comparison
- ICU LOS Comparison
- Weekend vs Weekday Admission Analysis

### Patient Demographics
- Age Distribution
- Gender Distribution
- Admission Type
- Top Admission Locations
- Top Discharge Locations

---

### Key Outcomes
- Built an end-to-end ETL pipeline using Informatica IDMC
- Integrated multiple clinical datasets for healthcare analytics
- Designed an interactive Power BI dashboard for comparative admission analysis
- Generated actionable insights on mortality, hospital stay, ICU utilization, and patient demographics
